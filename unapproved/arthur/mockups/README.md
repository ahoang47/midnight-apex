# Unapproved mockups (Art)

Concept and UI mockups for review. Not approved by Austin. Proposals only; anything approved moves out of `unapproved/arthur/` into the docs or assets. Exception: the `tones/` blend50 values are approved as art_direction B.2a. Build scripts are included. Blender scenes, raw passes, full-size CRT renders and logs are left out to keep the repo small.

On 2026-11-13 Austin approved deleting these superseded or experiment-only studies. They are gone from the tree and remain in git history: `lane_chain/`, `line_clash/` (option A already lives in `art/ui/line_vs_line/`; option B was not chosen), `psx_road_test/`, `crt/`, `race_state_study/`, and `pattern_read/`.

`line_preview/` and `resource_meters/` use the current POW / EN / HAN and IN / MID / OUT naming. Some older frames still in this folder (for example `tones/entry_*.png`) predate that canon and were not re-rendered.

- `overworld/`: Harbor Flats overworld mockup
- `tones/`: colour tone study. `blend50` is the approved night palette (art_direction B.2a)
- `line_preview/`: unapproved Godot B.5d line-preview frames (flat stance-coloured chevrons on a pack road, copy of Gordon's two-corner scenes). Austin called these good enough as reference for Gordon.
- `resource_meters/`: unapproved concept for a resource-meter stack (fuel / brakes / suspension)
