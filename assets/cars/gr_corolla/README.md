# car_gr_corolla — Toyota GR Corolla (2022, GR-FOUR hatch), lean game version

Game-ready import of the detail pass. Source, build scripts and review renders: `art/vehicles/gr_corolla/` (README there).

| | |
|---|---|
| Files | `car_gr_corolla.glb` (glTF binary, textures **embedded**: `gr_corolla_body` 1024², `gr_corolla_parts` 256², `gr_corolla_glow` 128×64; PNG sources and the env map in `art/vehicles/gr_corolla/detail/tex/`), `car_gr_corolla.tscn` (ready-made VehicleBody3D scene, see below), `susp_follow.gd` (+ `.uid`) |
| Triangles | **1,888** total (cap 2,000), incl. wheels, struts/arms and FX quads |
| Blueprint IoU | side 0.978, top 0.991, front 0.978, rear 0.978 (gate side/top ≥ .95, front/rear ≥ .92) |
| Clearance | 9 poses (lock −30/0/+30° × bump/static/droop): all clear, tightest 7.6 mm (FL/FR, straight ahead, full bump) |

**Glow FX:** `GRC_FX_LampGlow` (head + tail lamp glow quads, 8 tris, counted in the total) is **hidden by default**.
Unhide it (or toggle `visible` from the light state) in Godot; it uses `gr_corolla_glow.png` (left half warm head
glow, right half red tail glow), additive, unshaded.

Materials in the .glb are plain Principled (baked albedo): `GRC_Paint_Body`, `GRC_Glass`, `GRC_Under`, `GRC_Lamp`,
`GRC_Wheel`, `GRC_FX_Glow`. The faked shine is the vehicle shader in `design/art/art_direction.md` A.8 (env map:
`art/vehicles/gr_corolla/detail/tex/gr_corolla_env.png`).

## Rig (Godot VehicleBody3D / VehicleWheel3D)
```
GRC-vehicle                 root, ground, mid-wheelbase                       -> VehicleBody3D "GRC" (import hint)
 ├─ GRC_Body                ONE mesh (incl. headlamp lenses, wing, mirrors, exhaust, liners), origin = COM estimate
 ├─ GRC_FX_LampGlow         head + tail glow quads (FX, off by default)
 ├─ Hub_FL-wheel …          empty at the static hub                            -> VehicleWheel3D "Hub_XX" (import hint)
 │   └─ Steer_FL / FR       front: rotates about local Y (vertical through the hub), ±30°
 │       └─ GRC_Wheel_FL    10-sided, origin = hub, spins about the axle
 └─ Susp_FL …               empty at the static hub: follows hub position + steer only, never spin
     └─ GRC_Susp_FL         strut + lower arm (16 tris)
```
| | front | rear |
|---|---|---|
| hub (glTF x, y, z) | ±.785, .321, +1.329 | ±.785, .321, −1.329 |
| tyre radius / width | .321 / .235 (235/40R18) | same |
| travel (clearance-tested) | +35 mm bump / −50 mm droop | +45 mm bump / −50 mm droop |

* Ride height: ground at y 0. The body origin (COM estimate) is 0.52 m up and 0.26 m forward of mid-wheelbase
  (glTF z +0.26).
* The front bump is smaller than the rear because the arch line sits only 2–4 cm above the tyre (A.2.7).

## Godot 4 setup
The .glb uses Godot axes: +Y up, **+Z forward, +X = car left**, ground at y 0. No node carries a rotation or scale.
The `-vehicle` / `-wheel` name suffixes are Godot import hints, so the import already gives a VehicleBody3D `GRC`
with four VehicleWheel3D `Hub_XX`.

**Option A — use `car_gr_corolla.tscn`** (inherited scene of the .glb). It sets: mass 1,475 kg; custom centre of mass
at the `GRC_Body` origin; a body collision box (1.80 × 0.95 × 4.35 m, bottom 0.325 m above the ground); on each wheel
radius .321, `suspension_travel` .085 front / .095 rear, rest length .15, stiffness 80, damping 1.6 / 2.2, friction
slip 3.0, steering on FL/FR, traction on all four (GR-FOUR AWD); wheels and `Susp_XX` raised by 0.0985 m so the
body settles at the design ride height (same rest/stiffness/lift as the WRX test rig); `susp_follow.gd` on each
`Susp_XX` (`wheel` = matching hub, `steers` on the front pair); `GRC_FX_LampGlow` hidden. Generated by
`art/vehicles/gr_corolla/godot/make_tscn.py`.

**Option B — set it up by hand** as for the other cars:
1. Import `car_gr_corolla.glb`. `GRC` is a VehicleBody3D; set `center_of_mass_mode = Custom` and use the `GRC_Body`
   position as `center_of_mass`.
2. On each `Hub_XX` (VehicleWheel3D) keep the transform and set `wheel_radius`, `suspension_travel` and
   `use_as_steering` (front) / `use_as_traction` as in the table. VehicleWheel3D moves, steers **and spins** its
   children, so `Steer_XX` → `GRC_Wheel_XX` stay under it.
3. Attach `susp_follow.gd` to each `Susp_XX` (a sibling of the wheels), set `wheel` to the matching wheel and
   `steers = true` on FL/FR. Each physics frame it copies the wheel's position (travel) and steering about +Y, never the spin.
4. Steering: keep `VehicleBody3D.steering` within ±0.524 rad (±30°); the wells were clearance-tested only to that lock.

**Verified** in Godot 4.6.3 (Compatibility / OpenGL3 fallback on llvmpipe, in a scratch copy of the repo): the .glb
imports, the scene loads with no script errors, the car settles at body y 0.000, drives and steers (22.9° at
steering .40), and the struts follow travel and steer. Screenshot sheet:
`art/vehicles/gr_corolla/detail/renders/gr_corolla_detail_godot46_800.jpg`. As with the WRX rig, Godot's raycast
wheels sit about 2 cm lower than the static hub at rest (wheel y ≈ .30 vs .321).
Note: the headless import in that scratch copy only ran after `filesystem/import/blender/enabled=false`, because the
repo's `.blend` sources make Godot look for Blender; this is not specific to this car.
